# WTracker – Workout Tracking Application

WTracker is a full-stack web application built to help users track their workouts in a simple and consistent way. The project was created to solve a personal problem of not having an easy-to-use system for logging and reviewing workout progress.

## 🚀 Features

- Add and track workouts
- Store and manage workout data
- Clean and simple user interface
- REST API-based backend
- Full-stack integration between frontend and backend

## 🛠 Tech Stack

**Frontend**
- React
- JavaScript
- HTML / CSS

**Backend**
- Django
- Django REST Framework

**Database**
- SQLite (development)

## ⚙️ How It Works

- The frontend (React) handles the user interface and user interactions.
- The backend (Django REST Framework) provides APIs to manage workout data.
- Data flows between frontend and backend using JSON-based API requests.

## 📚 What I Learned

- Building and structuring REST APIs using Django
- Connecting frontend and backend in a full-stack application
- Managing state and data flow in React
- Debugging API issues and handling asynchronous data
- Thinking from a user perspective while building features
